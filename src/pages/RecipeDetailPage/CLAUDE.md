# recipe detail page

## 1. 페이지 설명

사용자가 작성된 레시피를 확인하는 페이지.

레시피 작성 페이지에서 입력된 모든 정보를 조회하는 구조로 구성한다.

## 2. 진입 경로

- 내 레시피 리스트 → 레시피 선택
- 레시피 작성 완료 → 상세 페이지 이동

## 3. 이탈 경로

| 상황           | 이동               |
| -------------- | ------------------ |
| 뒤로가기       | 이전 페이지        |
| 수정 버튼 클릭 | 레시피 수정 페이지 |

## 4. 화면 구성

### 상단 영역

| UI 요소       | 설명                    |
| ------------- | ----------------------- |
| 뒤로가기 버튼 | 이전 페이지 이동        |
| 페이지 타이틀 | 레시피 제목             |
| 수정 버튼     | 레시피 수정 페이지 이동 |

### 조회 영역

| 영역         | 구성              |
| ------------ | ----------------- |
| 기본 정보    | 제목, 대표 이미지 |
| 설명         | 요리에 대한 설명  |
| 태그         | 요리 태그         |
| 총 조리 시간 | 시간, 분          |
| 몇 인분      | 몇 인분           |
| 재료         | 재료 리스트       |
| 사전 준비    | 준비 리스트       |
| 조리 순서    | 단계 리스트       |

## 5. 사용자 시나리오

### 5.1 레시피 조회

1. 사용자가 레시피 상세 페이지에 진입한다.
2. 서버로부터 레시피 데이터를 조회한다.
3. 기본 정보(제목, 대표 이미지)를 표시한다.
4. 설명을 표시한다.
5. 태그를 표시한다.
6. 총 조리 시간을 표시한다.
7. 재료 리스트를 표시한다.
8. 사전 준비 리스트를 표시한다.
9. 조리 순서 리스트를 표시한다.

### 5.2 레시피 수정 이동

1. 사용자가 수정 버튼을 클릭한다.
2. 레시피 수정 페이지로 이동한다.

## 6. 기능 명세

| 기능        | 동작                  | 성공 시          | 실패 시          |
| ----------- | --------------------- | ---------------- | ---------------- |
| 레시피 조회 | ID로 레시피 조회 요청 | 데이터 표시      | 에러 메시지 표시 |
| 수정 이동   | 수정 버튼 클릭        | 수정 페이지 이동 | -                |
| 뒤로가기    | 이전 페이지 이동      | 이전 페이지      | -                |

## 7. 세부 입력 구조

### 7.1 기본 정보

| 필드        | 설명            |
| ----------- | --------------- |
| 제목        | 레시피 이름     |
| 대표 이미지 | 대표 이미지 URL |

### 7.2 태그

| 필드 | 설명          |
| ---- | ------------- |
| 태그 | 문자열 리스트 |

### 7.3 재료

| 필드   | 설명   |
| ------ | ------ |
| name   | 재료명 |
| amount | 수량   |
| unit   | 단위   |

### 7.4 사전 준비

| 필드 | 설명      |
| ---- | --------- |
| 내용 | 준비 작업 |

### 7.5 조리 순서

| 필드        | 설명                     |
| ----------- | ------------------------ |
| description | 단계 설명                |
| imageUrl    | 단계 이미지              |
| duration    | 소요 시간 (시간, 분, 초) |
