# signup page

## 1. 페이지 설명

사용자가 이메일, 비밀번호, 닉네임을 입력하여 계정을 생성하는 페이지.

회원가입 완료 시 로그인 상태로 전환하지 않고,
로그인 페이지로 이동하여 로그인하도록 유도한다. (MVP 기준)

## 2. 진입 경로

- 로그인 페이지에서 "회원가입" 버튼 클릭

## 3. 이탈 경로

| 뒤로가기      | 로그인 페이지 |
| 회원가입 취소 | 로그인 페이지 |

## 5. 사용자 시나리오

1. 사용자가 이메일을 입력한다.
2. 사용자가 이메일 인증 버튼을 클릭한다.
3. 입력한 이메일로 인증 코드가 발송된다.
4. 이메일 인증 버튼 문구가 재전송으로 변경된다.
5. 이메일 인증 버튼은 10초 동안 비활성화된다.
6. 사용자가 이메일에 발송된 인증 코드를 입력한다.
7. 이메일 인증 코드 확인 버튼을 클릭한다.
8. 인증 코드 검증을 수행한다.
9. 사용자가 비밀번호, 비밀번호 확인, 닉네임을 입력한다.
10. 사용자가 닉네임 중복 확인 버튼을 클릭한다.
11. 입력값 검증 수행
    - 이메일 형식 확인
    - 이메일 인증 완료 여부 확인
    - 비밀번호 조건 확인
    - 비밀번호 일치 여부 확인
    - 닉네임 조건 확인
    - 닉네임 중복 확인 여부 확인
12. 회원가입 버튼을 클릭한다.
13. 회원가입 API 요청 수행
14. 회원가입 성공 시 로그인 페이지로 이동한다.
15. 회원가입 실패 시 에러 메시지를 표시한다.

## 8. API 명세

### 1) 이메일 인증 코드 발송

| 항목     | 내용                              |
| -------- | --------------------------------- |
| API 목적 | 이메일 인증 코드 발송             |
| Method   | POST                              |
| Endpoint | /api/auth/email/verification-code |

**Request**

```json
{
  "email": "string"
}
```

**Response 성공**

```json
{
  "success": true
}
```

**Response 실패**

```json
{
  "message": "이미 가입된 이메일입니다."
}
```

### 2) 이메일 인증 코드 확인

| 항목     | 내용                                      |
| -------- | ----------------------------------------- |
| API 목적 | 이메일 인증 코드 검증                     |
| Method   | POST                                      |
| Endpoint | /api/auth/email/verification-code/confirm |

**Request**

```json
{
  "email": "string",
  "code": "string"
}
```

**Response 성공**

```json
{
  "verified": true
}
```

**Response 실패**

```json
{
  "message": "인증 코드가 올바르지 않습니다."
}
```

### 3) 닉네임 중복 확인

| 항목     | 내용                                          |
| -------- | --------------------------------------------- |
| API 목적 | 닉네임 중복 여부 확인                         |
| Method   | GET                                           |
| Endpoint | /api/users/check-nickname?nickname={nickname} |

**Response 성공**

```json
{
  "available": true
}
```

**Response 실패**

```json
{
  "message": "이미 사용 중인 닉네임입니다."
}
```

### 4) 회원가입

| 항목     | 내용             |
| -------- | ---------------- |
| API 목적 | 사용자 회원가입  |
| Method   | POST             |
| Endpoint | /api/auth/signup |

**Request**

```json
{
  "email": "string",
  "password": "string",
  "password중복확인": "string",
  "nickname": "string"
}
```

**Response 성공**

```json
{
  "email": "string",
  "nickname": "string"
}
```

**Response 실패**

```json
{
  "message": "이미 가입된 이메일입니다."
}
```
