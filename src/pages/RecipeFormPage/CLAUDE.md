# recipeform page

## 1. 페이지 설명

사용자가 새로운 레시피를 작성하거나 기존 레시피를 수정하는 페이지.

단일 페이지 내에서 모든 레시피 정보를 입력하는 구조로 구성한다.

## 2. 진입 경로

- 내 레시피 리스트 → "레시피 작성" 버튼
- 레시피 상세 → "수정" 버튼

## 3. 이탈 경로

| 상황      | 이동                               |
| --------- | ---------------------------------- |
| 작성 완료 | 레시피 상세 페이지                 |
| 작성 취소 | 내 레시피 리스트 페이지            |
| 뒤로가기  | 작성 중 이탈 확인 후 리스트 페이지 |

## 4. 화면 구성

### 상단 영역

| UI 요소       | 설명                          |
| ------------- | ----------------------------- |
| 뒤로가기 버튼 | 리스트로 이동                 |
| 페이지 타이틀 | "레시피 작성" / "레시피 수정" |
| 저장 버튼     | 우측 상단                     |

### 입력 영역

| 영역         | 구성                        |
| ------------ | --------------------------- |
| 기본 정보    | 제목<br>대표 이미지 (선택)  |
| 설명         | 요리에 대한 설명, 팁 (선택) |
| 태그         | 요리 태그 (선택)            |
| 총 조리 시간 | 시간, 분 (선택)             |
| 인분         | N인분 (선택)                |
| 재료         | 재료 리스트                 |
| 사전 준비    | 준비 리스트 (선택)          |
| 조리 순서    | 단계 리스트                 |

## 5. 사용자 시나리오

### 5.1 레시피 생성

1. 사용자가 레시피 작성 페이지에 진입한다.
2. 제목을 입력한다.
3. 대표 이미지를 업로드한다. (선택)
4. 설명을 입력한다. (선택)
5. 태그를 입력한다. (선택)
6. 총 조리 시간을 입력한다. (선택)
7. 몇 인분인지 입력한다. (선택)
8. 재료를 1개 이상 추가한다.
9. 사전 준비 항목을 추가한다. (선택)
10. 조리 순서를 1개 이상 추가한다.
11. 저장 버튼을 클릭한다.
12. 입력값 검증 수행
    - 제목 입력 여부
    - 재료 1개 이상 여부
    - 조리 순서 1개 이상 여부
13. 레시피 생성 API 요청 수행
14. 성공 시 → 레시피 상세 페이지 이동
15. 실패 시 → 에러 메시지 표시

### 5.2 레시피 수정

1. 사용자가 레시피 수정 페이지에 진입한다.
2. 기존 데이터가 입력 필드에 채워진 상태로 표시된다.
3. 사용자가 내용을 수정한다.
4. 저장 버튼을 클릭한다.
5. 입력값 검증 수행
6. 레시피 수정 API 요청 수행
7. 성공 시 → 레시피 상세 페이지 이동
8. 실패 시 → 에러 메시지 표시

## 7. 입력값 검증

| 항목         | 필수 | 조건                     | 에러 문구                          |
| ------------ | ---- | ------------------------ | ---------------------------------- |
| 제목         | Y    | 공백 불가                | 제목을 입력해주세요.               |
| 대표 이미지  | N    | 최대 5MB                 | -                                  |
| 설명         | N    | 최대 100자               | -                                  |
| 태그         | N    | 문자열 리스트, 최대 10개 | -                                  |
| 총 조리 시간 | N    | 00시간 00분              | -                                  |
| N인분        | N    | 00인분                   | -                                  |
| 재료         | Y    | 1개 이상                 | 재료를 1개 이상 입력해주세요.      |
| 재료 이름    | Y    | 공백 불가                | 재료명을 입력해주세요.             |
| 재료 수량    | N    | 숫자                     | -                                  |
| 재료 단위    | N    | 문자열                   | -                                  |
| 사전 준비    | N    | 문자열 리스트            | -                                  |
| 조리 순서    | Y    | 1개 이상                 | 조리 순서를 1개 이상 입력해주세요. |
| 단계 설명    | Y    | 공백 불가                | 단계 설명을 입력해주세요.          |
| 단계 이미지  | N    | 최대 5MB                 | -                                  |
| 단계 시간    | N    | 00시간 00분 00초         | -                                  |

저장 버튼 활성화 조건

- 제목 입력 완료
- 재료 1개 이상 존재
- 조리 순서 1개 이상 존재
- 각 조리 단계에 description 존재

## 8. 세부 입력 구조

### 8.1 기본 정보

| 필드        | 설명                               |
| ----------- | ---------------------------------- |
| 제목        | 레시피 이름 (필수)                 |
| 대표 이미지 | 대표 이미지 URL (선택)<br>최대 5MB |

### 8.2 태그

| 필드 | 설명                                |
| ---- | ----------------------------------- |
| 태그 | 문자열 리스트 (선택)                |
| 제한 | 최대 10개 권장                      |
| 기능 | 입력을 누르면 기본 태그를 선택 가능 |

### 8.3 재료

| 필드   | 설명                                        |
| ------ | ------------------------------------------- |
| name   | 재료명 (필수)                               |
| amount | 수량                                        |
| unit   | 단위<br>입력을 누르면 기본 태그를 선택 가능 |
| 기능   | 추가 / 삭제 / 순서 변경                     |

### 8.4 사전 준비

| 필드 | 설명                           |
| ---- | ------------------------------ |
| 내용 | 준비 작업 (선택)<br>최대 300자 |
| 기능 | 추가 / 삭제 / 순서 변경        |

### 8.5 조리 순서

| 필드        | 설명                            |
| ----------- | ------------------------------- |
| description | 단계 설명 (필수)<br>최대 300자  |
| imageUrl    | 단계 이미지 (선택)<br>최대 5MB  |
| duration    | 소요 시간 (시간, 분, 초) (선택) |

## 9. API 명세

### 1) 레시피 생성

| 항목     | 내용         |
| -------- | ------------ |
| Method   | POST         |
| Endpoint | /api/recipes |

```json
{
  "title": "string",
  "thumbnailUrl": "string",
  "description": "string",
  "tags": ["string"],
  "cookTime": {
    "hour": "number",
    "minute": "number"
  },
  "portion": "number",
  "ingredients": [
    {
      "orderNumber": "number",
      "name": "string",
      "amount": 0,
      "unit": "string"
    }
  ],
  "preparations": [
    {
      "orderNumber": "number",
      "content": "string"
    }
  ],
  "steps": [
    {
      "orderNumber": "number",
      "description": "string",
      "imageUrl": "string",
      "duration": {
        "hour": "number",
        "minute": "number",
        "second": "number"
      }
    }
  ]
}
```

### 2) 레시피 수정

| 항목     | 내용              |
| -------- | ----------------- |
| Method   | PUT               |
| Endpoint | /api/recipes/{id} |

(요청 구조 동일)

### 3) 이미지 업로드

| 항목     | 내용        |
