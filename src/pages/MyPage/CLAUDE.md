# my page

## 1. 페이지 설명

사용자의 기본 계정 정보를 확인하는 페이지.

MVP에서는 복잡한 기능 없이
이메일, 닉네임 등 사용자 기본 정보만 표시한다.

## 2. 진입 경로

| 진입 위치               | 동작                           |
| ----------------------- | ------------------------------ |
| 내 레시피 리스트 페이지 | 우측 상단 마이페이지 버튼 클릭 |

## 3. 이탈 경로

| 상황           | 이동                    |
| -------------- | ----------------------- |
| 뒤로가기       | 내 레시피 리스트 페이지 |
| 설정 버튼 클릭 | 설정 페이지             |

## 4. 화면 구성

| UI 요소       | 설명               | 필수 여부 | 비고 |
| ------------- | ------------------ | --------- | ---- |
| 뒤로가기 버튼 | 이전 화면 이동     | Y         |      |
| 페이지 타이틀 | "마이페이지"       | Y         |      |
| 사용자 닉네임 | 닉네임 표시        | Y         |      |
| 사용자 이메일 | 로그인 이메일 표시 | Y         |      |
| 설정 버튼     | 설정 페이지 이동   | Y         |      |

## 5. 사용자 시나리오

1. 사용자가 마이페이지에 진입한다.
2. 서버 또는 로컬에서 사용자 정보를 조회한다.
3. 이메일 및 닉네임을 화면에 표시한다.
4. 사용자가 설정 버튼을 클릭한다.
5. 설정 페이지로 이동한다.

## 6. 기능 명세

| 기능             | 동작             | 성공 시                 | 실패 시          |
| ---------------- | ---------------- | ----------------------- | ---------------- |
| 사용자 정보 조회 | 사용자 정보 표시 | 화면 표시               | 에러 메시지 표시 |
| 설정 이동        | 설정 버튼 클릭   | 설정 페이지 이동        | -                |
| 뒤로가기         | 이전 화면 이동   | 내 레시피 리스트 페이지 | -                |

## 7. 데이터 표시 명세

| 항목   | 설명          |
| ------ | ------------- |
| 이메일 | 로그인 이메일 |
| 닉네임 | 사용자 닉네임 |

※ MVP에서는 서버 호출 없이 로그인 시 받은 user 정보 사용 가능

## 8. API 명세

### 사용자 정보 조회

| 항목     | 내용          |
| -------- | ------------- |
| Method   | GET           |
| Endpoint | /api/users/me |

**Response**

```json
{
  "email": "string",
  "nickname": "string"
}
```

## 9. 에러 처리

| 상황          | 메시지                        |
| ------------- | ----------------------------- |
| 네트워크 오류 | 네트워크 오류가 발생했습니다. |

## 10. 권한 및 보안

| 항목   | 내용                      |
| ------ | ------------------------- |
| 인증   | 로그인 상태에서만 접근    |
| 데이터 | 본인 정보만 표시          |
| 토큰   | Authorization Header 사용 |

## 11. 추후 확장 고려

- 프로필 이미지
  - 추가, 삭제, 변경
- 닉네임 변경
  - N개월에 한번 씩
- 작성 레시피 수
- 좋아요 or 팔로잉/팔로워 수
- 계정 활성화/비활성화
- 이메일 변경
  - 중복 체크, 이메일 유효성 체크
- 본인이 쓴 댓글 확인
- 내 약력
- 내 설명
- 인사말
- pro 계정 표시
