# login page

## 1. 페이지 설명

사용자가 이메일과 비밀번호를 입력하여 서비스에 로그인하는 페이지.

인증 성공 시 사용자 세션을 생성하고,
AccessToken을 OS 보안 저장소에 저장한 뒤 내 레시피 리스트 페이지로 이동한다.

## 2. 진입 경로

- 앱 최초 실행 시
- 게스트
  - 기본은 메인으로 가야함
  - 나중에 확장 고려해서
  - mvp 기능 상 처음은 로그인으로 가는게 맞는데, 이거를 클라에서 첫 화면을 로그인으로 하면 나중에 이 접속 페이지를 바꿀때 좀 문제될수가있다
  - 첫 페이지를 메인페이지로 할건데, 클라에서임의로 로그인으로 바로이동하게끔 리다이렉트 시킬거다
- 회원가입 완료 이후

## 3. 이탈 경로

| 상황               | 이동                    |
| ------------------ | ----------------------- |
| 로그인 성공        | 내 레시피 리스트 페이지 |
| 회원가입 버튼 클릭 | 회원가입 페이지         |
| 뒤로가기 (Android) | 앱 종료                 |

## 4. 화면 구성

| UI 요소                   | 설명                 | 필수 여부 | 비고                                            |
| ------------------------- | -------------------- | --------- | ----------------------------------------------- |
| 이메일 입력창             | 이메일 입력          | Y         | placeholder: "Email"                            |
| 비밀번호 입력창           | 비밀번호 입력        | Y         | secureTextEntry 적용<br>placeholder: "Password" |

## 5. 사용자 시나리오

1. 사용자가 이메일과 비밀번호를 입력한다.
2. 로그인 버튼을 클릭한다.
3. 입력값 검증 수행
   - 이메일 형식 확인
   - 비밀번호 입력 여부 확인
4. 로그인 API 요청 수행
5. 로그인 성공 시
   - accessToken을 OS 보안 저장소에 저장
   - 내 레시피 리스트 페이지로 이동
6. 로그인 실패 시
   - 에러 메시지 표시

## 6. 기능 명세

| 기능          | 동작                          | 성공 시            | 실패 시          |
| ------------- | ----------------------------- | ------------------ | ---------------- |
| 로그인        | 이메일/비밀번호로 로그인 요청 | 리스트 페이지 이동 | 에러 메시지 표시 |
| 회원가입 이동 | 회원가입 페이지로 이동        | 회원가입 페이지    | 에러 메시지 표시 |
| 입력 검증     | 입력값 유효성 체크            | 버튼 활성화        | 버튼 비활성화    |

## 7. 입력값 검증

| 필드   | 필수 | 조건        | 에러 문구                          |
| ------ | ---- | ----------- | ---------------------------------- |
| 이메일 | Y    | 이메일 형식 | 올바른 이메일 형식을 입력해주세요. |

버튼 활성화 조건

- 이메일 입력됨
- 비밀번호 입력됨

## 8. API 명세

### 로그인

| 항목     | 내용            |
| -------- | --------------- |
| API 목적 | 사용자 로그인   |
| Method   | POST            |
| Endpoint | /api/auth/login |

**Request**

```json
{
  "email": "string",
  "password": "string"
}
```

**Response (성공)**

```json
{
  "accessToken": "string",
  "user": {
    "id": "number",
    "nickname": "string"
  }
}
```

**Response (실패)**

```json
{
  "message": "이메일 또는 비밀번호가 올바르지 않습니다."
}
```

## 9. 에러 처리

| 상황                    | 메시지                                           |
| ----------------------- | ------------------------------------------------ |
| 이메일 형식 오류 - 클라 | 올바른 이메일 형식을 입력해주세요.               |
| 로그인 실패 - 백        | 이메일 또는 비밀번호가 올바르지 않습니다.        |
| 네트워크 오류 - 백      | 네트워크 오류가 발생했습니다. 다시 시도해주세요. |

## 10. 권한 및 보안

| 항목        | 내용                                                         |
| ----------- | ------------------------------------------------------------ |
| 인증 방식   | JWT 기반 인증                                                |
| 토큰 저장   | OS 보안 저장소 사용                                          |
