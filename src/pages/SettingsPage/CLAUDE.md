# settings page

## 1. 페이지 설명

사용자가 앱 및 계정 관련 설정을 확인하고 로그아웃, 회원탈퇴를 수행하는 페이지.

## 2. 진입 경로

| 진입 위치  | 동작           |
| ---------- | -------------- |
| 마이페이지 | 설정 버튼 클릭 |

## 3. 이탈 경로

| 상황          | 이동          |
| ------------- | ------------- |
| 뒤로가기      | 마이페이지    |
| 로그아웃 성공 | 로그인 페이지 |

## 4. 화면 구성

| UI 요소       | 설명              | 필수 여부 | 비고                              |
| ------------- | ----------------- | --------- | --------------------------------- |
| 뒤로가기 버튼 | 마이페이지로 이동 | Y         |                                   |
| 페이지 타이틀 | "설정"            | Y         |                                   |
| 로그아웃 버튼 | 로그아웃 실행     | Y         | 강조 스타일 또는 위험 액션 스타일 |
| 회원탈퇴 버튼 | 회원탈퇴 실행     | Y         | 강조 스타일 또는 위험 액션 스타일 |

## 5. 사용자 시나리오

1. 사용자가 설정 페이지에 진입한다.
2. 사용자가 로그아웃 버튼을 클릭한다.
3. 로그아웃 확인 팝업을 노출한다.
4. 사용자가 확인을 선택한다.
5. OS 보안 저장소에서 accessToken을 삭제한다.
6. 앱 인증 상태를 초기화한다.
7. 로그인 페이지로 이동한다.

## 6. 기능 명세

| 기능     | 동작               | 성공 시            | 실패 시          |
| -------- | ------------------ | ------------------ | ---------------- |
| 로그아웃 | 로그아웃 버튼 클릭 | 로그인 페이지 이동 | 에러 메시지 표시 |
| 회원탈퇴 | 회원탈퇴 버튼 클릭 | 로그인 페이지 이동 | 에러 메시지 표시 |
| 뒤로가기 | 이전 화면 이동     | 마이페이지         | -                |

## 7. 로그아웃/회원탈퇴 처리

동작

1. OS 보안 저장소에서 accessToken 삭제
2. 앱 전역 인증 상태 초기화
3. 로그인 페이지로 이동
4. Navigation Stack reset

## 8. 로그아웃/회원탈퇴 확인 팝업

로그아웃 하시겠습니까? / 회원 탈퇴 시, 모든 레시피가 삭제됩니다. 하시겠습니까?

| 버튼              | 동작                   |
| ----------------- | ---------------------- |
| 취소              | 팝업 닫기              |
| 로그아웃/회원탈퇴 | 로그아웃/회원탈퇴 처리 |

## 9. API 명세

### 회원탈퇴

| 항목     | 내용             |
| -------- | ---------------- |
| API 목적 | 사용자 계정 탈퇴 |
| Method   | DELETE           |
| Endpoint | /api/users/me    |

**Response (성공)**

```json
{
  "success": true
}
```

**Response (실패)**

```json
{
  "message": "네트워크 오류가 발생했습니다."
}
```

## 10. 에러 처리

| 상황          | 메시지                        |
| ------------- | ----------------------------- |
| 네트워크 오류 | 네트워크 오류가 발생했습니다. |
